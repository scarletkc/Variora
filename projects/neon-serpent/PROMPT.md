# Neon Serpent

Build a playable first-person 3D snake game using Three.js, set in a futuristic Japanese city with a cyberpunk neon aesthetic. The snake collects energy, grows a body that follows it, and avoids obstacles and itself. Deliver the game as an HTML application. Decide the gameplay details, visual style, controls, and implementation yourself.

Create visual and audio assets in code. Do not use external visual or audio assets or asset-generation services.

Follow the [repository rules](../../AGENTS.md).
